Weighting

Raking adjusts each respondent’s contribution so that the weighted sample matches the available population margins. It is performed after data cleaning and before finalising the CTI configuration.

RakingAge × gender + geographyWeights capped at 4Download the Rmd script ↓

Purpose and expected result

Weighting corrects differences between the sample structure and the reference population. It changes neither raw responses nor collected categories: it assigns a weight to each respondent for analysis and charts.

The script uses raking, also known as iterative proportional fitting. This method adjusts several dimensions simultaneously without multiplying separate weights, reducing the risk of unstable weights.

Before you begin

Survey data must be cleaned, with one row per respondent and harmonised categories. Population data must cover the same age bands, genders and geographic entities.

Recommended approach

Prepare the margins before running the script. Any label difference between survey and population data must be resolved before calculation.

1. Prepare population margins

Margins represent the population distribution for each selected dimension. Level names must exactly match the values in the survey data.

MarginMinimum / optionalExpected structure in the population file
Age × genderMinimum requirementage sheet: AGEgroup, Gender, Freq. Strata are built in the form 18-29_Female.
GeographyMinimum requirementgeo sheet: the area column and Pop. Select the same administrative level as in the survey.
Additional strataUp to 3, if reliable margins are availableFor example education or employment; each sheet contains Level and Percentage.

Selecting strata

Age, gender and location form the core of calibration. Then add up to three strata when population data are available, reliable and match the categories collected. Strata must remain compatible with the sample size.

Variables used in the survey and population are declared in the script: geo_var1 and geo_var2 for geography, then flex_survey_vars and flex_tabs for additional strata.

Watch for small cells

A detailed stratum is useful only if all its categories are present in the sample. If a population category is absent from the survey, raking stops: group response options or remove that margin before trying again.

2. Check matches

Before running the script, compare the unique values of each calibration variable with the corresponding margins. There must be no missing category or extra category in the sample.

  • Age bands are identical, for example 18-29, 30-39, 40-49, 50-59 and 60+.
  • Gender categories are identical in both files.
  • Geographic names use the same spelling, case, accents, hyphens and spaces.
  • Optional strata use the same labels in the survey and population margins.

Common sources of error

A category may disappear after missing values are excluded for another stratum. Also check for invisible spaces, different dashes and changes in upper/lower case.

3. Run raking and stabilise weights

The script creates a survey design with an initial weight of 1, then calibrates weights so weighted margins match population proportions.

01

Iterative calibration

Raking uses all valid margins simultaneously, with a maximum of 50 iterations and a convergence tolerance of 1e-6.

02

Handling uncalibrated cases

Complete respondents present in every margin are used for calibration. In the script output, excluded cases receive a weight of 1.

03

Capping

Raking weights are capped at 4 to limit the undue influence of a small number of respondents.

04

Normalisation

Capped weights are then divided by their mean: the final mean weight equals 1.

Conceptually, weights increase for under-represented groups and decrease for over-represented groups. Raking determines the joint adjustment; do not manually multiply ratios by stratum.

4. Read the diagnostics

Do not validate weights without reviewing the overall summary and stratum-level table produced by the script.

IndicatorWhat it checksWhat to look for
MeanWeight normalisation.It should be close to 1.
Min / MaxRange of assigned weights.The final maximum must not exceed 4.
SD / CVWeight dispersion.High dispersion indicates demanding calibration or sparse cells.
Effective sample sizeSample size after accounting for weights: (Σw)² / Σ(w²).Compare it with the original sample size. An efficiency of 60–80% is generally acceptable; below 50%, review the margins.
strata_weight_summaryStratum-level comparison of count, sample proportion, population proportion and mean weight.Check that adjustments are plausible for every group.

Output file

The script exports a weighted Excel file to the country folder. It is then used as the basis for CTI analysis and contains:

  • data : survey data with the weight column ;
  • weight_summary : the overall weight summary ;
  • strata_weight_summary : the detailed diagnostics by margin and stratum.

Traceability

Keep the version of the population file, raking parameters and exported weighted file with the project. They make it possible to explain differences between raw and weighted results.

Checklist before configuration

  • The survey file contains one row per respondent and the expected calibration columns.
  • Age × gender and geographic margins match the collected data.
  • Additional strata are limited to three and are based on reliable population data.
  • All population categories are present in the sample retained for raking.
  • Labels match exactly between the survey and population tables.
  • The final weight is capped at 4 then normalised to a mean of 1.
  • The weight summary and effective sample size have been checked.
  • The weighted file and its diagnostics are saved in the country folder.
