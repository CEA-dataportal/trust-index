Report generation

The R Markdown template automatically assembles weighted data, country configuration, translations, charts and tables into an interactive CTI report. The country team completes the narrative and key messages; standard scripts produce the analysis.

What the template does

The Country-Report-template.Rmd file is the report’s master document. When rendered (“Knit”), it runs the required R scripts, creates analysis objects, inserts charts and assembles country-specific narrative text.

HTML is the reference format: it preserves the table of contents, tabs, download buttons and interactive maps. The report is self-contained through the self_contained: true option.

Prerequisites

The configuration file, weighted data, population tables and shapefiles must already be finalised. Run the report from the country project folder and check that repo points to the CTI repository.

Report structure

The document combines country-specific narrative content with automatically calculated sections. Conditional blocks display only analyses available for the selected module and configured variables.

Inputs

The country, module, configuration file and working path are defined at the start of the Rmd.

Analysis

Scripts load data, settings and translations, then prepare scores and diagnostics.

Report

Narrative text, charts, maps and tables are inserted into report sections.

Export

The HTML report is created and export.R prepares downloadable files and data outputs.

1. Settings to complete at the start of the Rmd

The input block contains the settings that connect the template to the country project. Update them before rendering the report.

ParameterPurposeExample
country_nameCountry name used to locate the working folder.Madagascar
config_fileExact name of the country configuration file.MDG_configuration.xlsx
moduleModule to analyse. Supported values are inst and ews.ews
pathPath to the country folder.file.path("..", country_name)
repoPath to the CTI repository; it enables the template to call shared scripts./…/trust-index

Render the report

In RStudio, open the Rmd, check the settings and use Knit. You can also use:

rmarkdown::render("Country-Report-template.Rmd")

Do not change the template without purpose

Keep standard object and chunk names. They control conditional displays, tabs, maps and downloads. Any structural change must be tested for both modules.

2. Scripts called and their roles

Standard scripts are called in a specific order. They should not normally be modified in the country Rmd.

GroupScripts calledFunction
Modulepalette_[module].R, config_[module].RLoads colours, dimensions, prefixes and settings specific to the Institutional or Early Warning module.
Configuration and datasetup.R, read_config.R, load_data.RInitialises the environment, reads the configuration file and loads data and required tables.
Translation and analysistranslation_v2.R, analysis.RApplies the report language, prepares variables and calculates scores, profiles and statistical checks.
Charts and tablescharts_sampling.R, charts_drivers.R, charts_score.R, charts_advanced.R, tables.RCreates sampling, results, factor, profile and map charts, as well as tables.
Outputsexport.RProduces exportable data used by the download button and publication outputs.

3. What the country team can modify

Areas marked input-required are intended to be completed. They allow the report to be adapted without changing calculations.

  • The title, country, module and configuration file.
  • The overall narrative summary and key findings.
  • Text on sampling, country context and survey limitations.
  • Interpretive comments on results and context-specific recommendations.
  • The report language and specific translations, through the configuration file and the translation sheet.

Keep standard

Do not modify called scripts, scoring rules, CTI prefixes, chart objects or export chunks without technical validation. Country adaptations should remain in the configuration, translations and narrative blocks of the Rmd.

4. What the report produces

Content appears according to the selected module, questions actually available and configured checks.

01

Summary and sampling

Key messages, respondent profile, geographic distribution, age-gender pyramid, population comparison and coverage maps.

02

Survey results

Drivers, contextual questions, risks and early warning, according to variables available in the module.

03

CTI scores

Overall scores, dimensions or pillars, disaggregation factors, geography and respondent profiles.

04

Methods and outputs

Descriptive tables, weighting, correlations, statistical tests and an exported-data download button.

Publish to PDF or Word if needed

Keep HTML as the reference version: tabs and Leaflet maps are interactive. For static distribution, temporarily add word_document or pdf_document to the YAML output section, then render the required format explicitly.

rmarkdown::render("Country-Report-template.Rmd", output_format = "word_document")

rmarkdown::render("Country-Report-template.Rmd", output_format = "pdf_document")

Publication tip

Check the static version before distribution: tabs become simple sections, interactive maps need a static alternative and PDF requires a LaTeX installation, such as TinyTeX.

For Word, plan a layout review and, if necessary, a reference .docx document. Do not replace the validated HTML report.

Checklist before publication

  • The country, module, configuration file and repository path are correct.
  • Weighted data and population tables used are the validated versions.
  • Text marked input-required has been replaced with country content.
  • Key messages, sampling description and limitations have been reviewed.
  • Charts and tables match the final data.
  • Maps and downloads work in the HTML report.
  • Specific translations have been checked in the publication language.
  • The PDF or Word version, if produced, has been reviewed after rendering.
