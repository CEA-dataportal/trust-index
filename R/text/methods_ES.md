**Metodología de cálculo de las puntuaciones**

Para determinar las puntuaciones, utilizamos el siguiente método:

1. **Estructura de la encuesta**

   La encuesta CTI incluye varias preguntas agrupadas en subdimensiones dentro de dos categorías principales:

   - Competencias (p. ej., fiabilidad, eficacia, capacidad técnica)
   - Valores (p. ej., ética, integridad, equidad, transparencia)

2. **Cálculo de las puntuaciones de las subdimensiones**

   Cada subdimensión comprende varios ítems (preguntas). Los encuestados responden utilizando una escala tipo Likert de 1 a 4; las respuestas « No sabe » se excluyen.

   Para cada subdimensión:

   *Puntuación de la subdimensión = ∑ (Puntuaciones ponderadas de las respuestas) / Número de ítems*

   Si las ponderaciones no se determinan empíricamente, generalmente se aplica la misma ponderación a cada ítem.

3. **Cálculo de las puntuaciones de las dimensiones**

   Una vez calculadas las puntuaciones de todas las subdimensiones, las puntuaciones de Competencias y Valores corresponden a la media aritmética de las puntuaciones de sus respectivas subdimensiones:

   - *Puntuación de Competencias = ∑ (Puntuaciones de las subdimensiones de Competencias) / n*

   - *Puntuación de Valores = ∑ (Puntuaciones de las subdimensiones de Valores) / m*

   donde *n* y *m* corresponden al número de subdimensiones de cada categoría.
