**How to read the correlation matrix**

1. **Find the row and column**

   Example: Awareness × Effectiveness = 0.80

   This means that these two dimensions have a strong positive relationship.

2. **Read the number inside the circle**

   Values range from –1 to +1.

**Interpretation**

| Value | Meaning |
|---|---|
| 0.00 | No relationship |
| 0.10–0.30 | Weak |
| 0.30–0.50 | Mild |
| 0.50–0.70 | Moderate |
| 0.70–1.00 | Strong |
| Negative values | Variables move in opposite directions |
