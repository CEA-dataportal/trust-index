**Testes de significância**

Para avaliar se as diferenças entre os grupos são estatisticamente significativas, utilizamos testes *t* para comparar as pontuações médias das perguntas sobre competências e valores entre os diferentes grupos. Para as perguntas analisadas, as diferenças observadas não são estatisticamente significativas, o que pode dever-se, em parte, ao reduzido tamanho das amostras em alguns grupos.

A tabela indica se os resultados das pessoas que receberam apoio, dos voluntários e das restantes pessoas inquiridas diferem significativamente entre si. Utilizamos um nível de confiança de 95% e ajustamos os valores de *p* para ter em conta comparações múltiplas.
