**Comment lire la matrice de corrélation**

1. **Repérez la ligne et la colonne**

   Exemple : Compréhension × Efficacité = 0,80

   Cela signifie que ces deux dimensions présentent une forte relation positive.

2. **Lisez la valeur indiquée dans le cercle**

   Les valeurs vont de –1 à +1.

**Interprétation**

| Valeur | Signification |
|---|---|
| 0,00 | Aucune relation |
| 0,10–0,30 | Faible |
| 0,30–0,50 | Légère |
| 0,50–0,70 | Modérée |
| 0,70–1,00 | Forte |
| Valeurs négatives | Les variables évoluent dans des directions opposées |
